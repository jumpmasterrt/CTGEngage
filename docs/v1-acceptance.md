# CTG Engage V1 acceptance checklist

V1 is fieldable only when every required item below passes on ExpoPi.

## Startup and recovery

- [ ] ExpoPi reaches CTG Engage without operator intervention after power-on.
- [ ] The kiosk recovers after an ordinary reboot and after power is restored.
- [ ] Engage launches and remains usable with the network disconnected.
- [ ] Visitors cannot reach the desktop, browser controls, or system settings through ordinary touch input.

## Visitor interaction

- [ ] Every primary action is comfortably tappable on the installed touchscreen.
- [ ] Both “Yes” and “No” complete the “Are you a gamer?” exchange.
- [ ] The “Yes” path accepts multiple selections and shows the matching result.
- [ ] The “No” path offers familiar non-video games and permits “still no.”
- [ ] Every discovery topic and chapter can be entered and exited.
- [ ] “Surprise me again” advances without an immediate repeat.
- [ ] “Start over” returns to the opening question from every completion path.
- [ ] Two minutes without interaction resets the experience to the opening question.

## Content and presentation

- [ ] Logos and the connection QR code render without a network connection.
- [ ] The QR code resolves to the intended CTG destination when scanned.
- [ ] No text is clipped at the kiosk’s native resolution and orientation.
- [ ] Factual claims, names, dates, and source labels have completed leadership review.
- [ ] The browser displays no first-run prompts, update banners, crash warnings, or navigation chrome.

## Field operation

- [ ] The restricted `ctgga` account can operate and restart the kiosk without administrator access.
- [ ] The `proxenos` administrator account can recover the kiosk and view service status.
- [ ] A first-time visitor can complete a useful path without coaching.
- [ ] A booth volunteer can recover the opening screen using one documented action.
- [ ] A booth operator can complete a clean touch-only shutdown before removing power.
- [ ] The first field test records observed failures, confusion, completion time, and abandoned paths.
